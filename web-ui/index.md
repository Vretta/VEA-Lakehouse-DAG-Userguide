# Web UI Guide

The VEA Data Lakehouse Dashboard provides a web-based interface for managing data assets, jobs, and exports. This guide covers how to use the dashboard to configure and run data processing workflows.

## Overview

The dashboard is accessible at `/test-ctrl/data-exporter/dashboard` and provides three main sections:

1. **Codebook**: Define and manage assets and jobs
2. **Export Jobs**: Create and monitor export job executions
3. **Test Windows**: View available test administration windows

## Documentation

- [Configuring Assets and Jobs](./configure.md): Learn how to define new assets and jobs, edit existing definitions, and manage preview versions
- [Running Export Jobs](./run.md): Learn how to create export jobs, configure parameters, and download results

## Quick Navigation

### Codebook Features
- Browse and filter available assets and jobs
- View asset dependencies and job configurations
- Create new assets and jobs
- Edit existing definitions (with preview support)
- View asset schemas and transformation details

### Export Jobs Features
- Create new export jobs with custom configurations
- Monitor job execution status
- Download completed export packages
- View and inspect individual asset outputs
- Export asset data as CSV

## Getting Started

1. **Access the Dashboard**: Navigate to the dashboard URL in your browser
2. **Explore the Codebook**: Review existing assets and jobs to understand the system
3. **Create an Export**: Follow the [Running Export Jobs](./run.md) guide to create your first export
4. **Define Custom Assets**: Use the [Configuring Assets and Jobs](./configure.md) guide to create custom data processing workflows
